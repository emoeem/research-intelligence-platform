# RIP 响应式布局规格

## 一、断点目标

| 区间 | 目标布局 |
|---|---|
| >= 1600px | 充分利用宽屏，可启用右侧 Inspector 与多列区域 |
| 1280-1599px | Sidebar 折叠优先，Inspector 默认收起 |
| 1024-1279px | 紧凑 Sidebar，Inspector 转 Drawer，工作区导航可滚动 |
| 768-1023px | Sidebar Drawer，表格水平滚动或紧凑列，Activity 转抽屉 |
| < 768px | 单列任务界面，SessionTabs 水平滚动，Request/Response 用切换 Tab |

断点最终以内容实际最小宽度为准，不能为了达到断点数字而导致内容溢出。

## 二、专业工作台行为

- HTTP History：桌面显示列表与请求/响应分栏；平板显示列表和详情 Tab；手机先显示列表，选择记录后进入详情页/抽屉。
- Repeater：桌面左右双栏；平板可切换 Request/Response；手机全屏切换面板，不缩小编辑器到不可用宽度。
- Workflow：桌面使用完整画布；移动端采用只读/简化编辑提示，并提供列表导航。
- Dashboard：网格自动重排；图表提供摘要或表格替代信息。
- DataTable：保留优先列，次要字段隐藏到行详情，不默认强制缩成小字。

## 三、窗口和滚动

- 页面主体在桌面上适应可视高度。
- 只有明确数据容器承担纵向滚动。
- 不允许页面、列表、详情三层互相抢滚动。
- Dialog / Drawer 打开时管理焦点和页面滚动锁。
- 面板收缩时设置 min-size，避免编辑区变成几像素宽。
