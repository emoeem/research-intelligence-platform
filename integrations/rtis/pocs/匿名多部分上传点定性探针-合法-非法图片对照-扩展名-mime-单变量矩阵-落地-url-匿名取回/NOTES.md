## 方法族: `upload`

### 执行框架

1. 匿名性: 不带任何凭据能否上传成功
2. 路径可控性: filename 是否参与存储路径（对比两次不同名）
3. 校验类型: 单变量只改扩展名，看哪些通过哪些拒（黑白名单判定）
4. 落地可取回: 返回的 URL 不带鉴权能否下载
5. 解析验证: 取回的是源码还是执行结果（决定能否 RCE）

### 常见误报（先排除这些，再下结论）

- HTTP 200 但业务码失败: 必须解析 body 里的 code
- 假成功: 返回了 URL 但实际 404
- 白名单严格但 SVG 可传: SVG 可带脚本，是存储型 XSS 的另一条路
- 取回是图片二进制: 说明不解析该扩展名，不能 RCE
