## 方法族: `infra`

### 执行框架

1. 确定你在打谁: 解析 IP → 确认是边缘还是源站（看响应头/证书）
2. 应用层判据: 用 Host 头 / SNI 区分同一 IP 上的不同站点
3. 四类判读: 默认站回退 / IP 白名单 / 停放页 / 真站点
4. 源站验证: 用 --resolve 直连候选 IP，对比与 CDN 的响应差异
5. 记录不确定性: 分不清的情况标「未确认」，不要写成结论

### 常见误报（先排除这些，再下结论）

- 把 CDN 边缘当源站: 所有绕过都无效，因为打的还是同一层
- 泛解析干扰: 随机子域也解析成功，导致 vhost 矩阵全是假阳性
- 证书不匹配: SNI 错了会 TLS 失败，看起来像「站点不存在」
- 端口开放 ≠ 服务可用: 端口通但协议不对（反代/蜜罐）
