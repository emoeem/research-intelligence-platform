## 方法族: `tenant`

### 执行框架

1. 确定租户标识: 子域 / header / 路径前缀 / token 里的 tenant 字段
2. 找隔离缺口: 同一 token 换租户标识，看数据是否串
3. 跨租户枚举: 用 A 租户的凭据访问 B 租户的资源 ID
4. 记录隔离边界: 哪些接口做了校验，哪些只在前端过滤

### 常见误报（先排除这些，再下结论）

- 前端切换: UI 上切了租户但请求头没变，实际还是同一租户
- 缓存串号: 响应被 CDN 按 URL 缓存，不同租户拿到同一份
- 隔离在网关层: 应用层无校验，但网关按 host 分流，绕过网关才有意义
