## 方法族: `recon`

### 执行框架

1. 确定范围: 主域 → 子域 → 同 IP 其它域 → 同证书其它域
2. 被动优先: CT 日志、DNS 历史、Wayback、证书 SAN，比爆破更全且无痕迹
3. 主动补充: 只在被动无结果时才对特定前缀做定向探测
4. 去重收敛: 按「响应指纹」而非域名去重（多个域名一套代码 = 一个目标）
5. 标记置信度: 每个资产标注「确认在线 / 推测存在 / 仅 DNS 记录」

### 常见误报（先排除这些，再下结论）

- 泛解析: 任意随机子域都能解析 → 爆破结果全是假阳性，必须先用随机子域对照
- 停放页: 域名解析成功但内容是出售页/广告页，不是目标资产
- CDN 回源: 你摸到的是边缘节点，真实源站要单独找
- 旧记录: DNS 历史里的 IP 可能早已下线
