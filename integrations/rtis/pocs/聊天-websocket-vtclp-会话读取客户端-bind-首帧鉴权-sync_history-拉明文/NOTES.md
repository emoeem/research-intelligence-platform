## 方法族: `miniapp`

### 执行框架

1. 静态优先: 解包 wxapkg / APK，拿 bundle 找接口和密钥
2. 补动态: 静态看不到的部分（运行时拼装的路由、加密后的参数）用 hook 补
3. 流量对照: 同一操作，对比「静态推断的请求」与「实际抓到的请求」
4. 协议还原: 二进制帧/自定义协议，先定帧头再定字段
5. 复现验证: 用还原出的协议客户端发出一个被服务端接受的请求

### 常见误报（先排除这些，再下结论）

- 开发者工具被禁用: 小程序会检测 devtools，需要 hook 掉检测而非硬开
- 请求在 native 层发出: Java 层 hook 不到，要下到 so
- 协议有状态: 首帧必须 bind/鉴权，后续帧才能读数据
- 流量加密: tcp 层看起来是乱码，实际是应用层加密，要先解包再看
